# Lahori Bowls

Real-time "build your bowl" ordering site for a Lahori street-food concept: pick a base,
protein, toppings and sauce and watch the bowl assemble live, layer by layer, before ordering.
Backed by a real Supabase project (menu pricing, orders, and an account/rewards module).

`admin.html` is the real, Supabase-Auth-gated staff dashboard used to run the kitchen side,
covering orders, menu, and staff accounts.
