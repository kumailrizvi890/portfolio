# Fast Bowls

Real-time "build your bowl" ordering site for a South Asian street-food concept: pick a base,
protein, toppings and sauce and watch the bowl assemble live, layer by layer, before ordering.
Runs on sample menu and order data while its Supabase backend is paused — the menu, orders and staff dashboard are sample content for now, not a live backend.

`admin.html` is a demo staff dashboard for the kitchen side,
covering orders, menu, and staff accounts, running on the same sample data.

Name, phone, email, and address shown in the demo are fictional placeholders, not a real business.
